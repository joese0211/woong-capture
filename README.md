## 설치하기

1. 받은 `woong-capture-windows.zip` 을 마우스 오른쪽 단추로 누르고 **[모두 압축 풀기]** 를 고릅니다.
2. 풀린 폴더 안의 **WoongCapture.exe** 를 두 번 누릅니다.
3. 파란 창 **"Windows의 PC 보호"** 가 뜨면 **[추가 정보]** → **[실행]** 을 누릅니다.
   (인증서를 사지 않은 작은 무료 프로그램이라 처음 한 번 보이는 안내예요.)
4. **"웅캡처 설치"** 창에서 **[설치하기]** 를 누르면 끝!
   화면 오른쪽 아래(시계 옆)에 강아지 아이콘이 생겨요. 안 보이면 작업 표시줄의 **[^]** 를 눌러 보세요.

설치는 내 계정에만 되고(`%LOCALAPPDATA%\Programs\WoongCapture`), 관리자 권한은 필요 없어요.
예전 버전이나 예전 이름 **hatelist01** 을 쓰고 있었다면 새로 설치할 때 자동으로 정리되고 설정은 그대로 옮겨져요.
설치가 끝나면 받은 압축 파일과 풀린 폴더는 지워도 돼요.

## 쓰는 법

### 캡처

| 하고 싶은 것 | 방법 |
|---|---|
| 캡처 시작 | **Alt + 2** |
| 원하는 부분만 | 끌어서 고르기 |
| 창 하나만 | 마우스를 창 위에 두고 한 번 누르기 |
| 화면 전체 | 위쪽 막대의 **[전체화면]** |
| 단축키 바꾸기 | 위쪽 막대의 **[설정]**, 또는 트레이 메뉴 **'단축키 설정…'** |
| 그만두기 | **Esc** |

- 캡처하면 **바로 복사**돼요. 카카오톡 · 메일 등에 **Ctrl + V** 로 붙여 넣으면 돼요.
- 편집기: 펜 · 형광펜 · 사각형 · 원 · 화살표 · 글자 · 모자이크
  — **Ctrl + C** 복사, **Ctrl + S** 저장, **Ctrl + Z** 되돌리기, **Esc** 닫기

### 최근 캡처 목록 (편집기 오른쪽)

- 캡처한 그림이 **최근 100장까지** 편집기 오른쪽에 작은 그림으로 쌓여요. 100장이 넘으면 오래된 것부터 정리돼요.
- 작은 그림을 **누르면** 그 그림을 다시 열어 꾸미고 복사 · 저장할 수 있어요. 꾸미던 것은 목록에 그대로 남아요.
- **[선택]** 을 누르고 여러 장을 고르면 한꺼번에 **저장하기 · 삭제하기**, 아래의 **[모두 저장] · [모두 삭제]** 도 있어요.
- 실수로 삭제했다면 10초 안에 **[되돌리기]** 를 누르세요. 목록은 왼쪽 가장자리의 **[›]** 로 접고 펼 수 있어요.

### 화면 녹화 (MP4)

| 하고 싶은 것 | 방법 |
|---|---|
| 녹화 시작 | **Alt + 3** → 끌어서 녹화할 부분 고르기 (놓으면 바로 시작) |
| 화면 전체 녹화 | 강아지 아이콘 오른쪽 단추 → **[전체화면 녹화]** |
| 캡처 막대에서 시작 | **Alt + 2** → 위쪽 막대의 **[녹화]** 누르고 → [직접지정] · [창] · [전체화면] 고르기 (다시 누르면 캡처로 돌아와요) |
| 멈추기 | **Alt + 3** 다시 누르기, 또는 영역 옆 막대의 **[■ 멈춤]**, 또는 강아지 아이콘 누르기 |
| 소리 · 화질 바꾸기 | 강아지 아이콘 오른쪽 단추 → **[녹화 설정]** |

- 녹화하는 동안 시간이 적힌 작은 막대와 영역 테두리가 떠요. 이 둘은 **영상에 찍히지 않아요.**
- 멈추면 저장 폴더에 `녹화_날짜_시간.mp4` 로 저장되고, **파일이 복사**돼 있어서 카카오톡 · 메일에 **Ctrl + V** 로 붙여 넣을 수 있어요.
- **소리**: 스피커로 나오는 소리가 같이 녹음돼요. 내 목소리는 **[녹화 설정] → [마이크도 녹음]** 을 켜면 같이 담겨요. 마우스 커서 · 초당 몇 장 · 화질도 같은 메뉴에서 고를 수 있어요.
- 녹화 도중 컴퓨터가 갑자기 꺼졌다면, 다음에 웅캡처를 켤 때 건진 부분을 `녹화_복구_…` 로 살려 줘요.
- 강아지 아이콘을 오른쪽 단추로 누르면 창 캡처 · 전체화면 캡처 · 영역 지정 녹화 · 전체화면 녹화 · 녹화 설정 · 단축키 설정 · 저장 폴더 열기 · 자동 실행 · 프로그램 정보 메뉴가 나와요.

## 보안 · 개인정보

- **인터넷에 연결하지 않아요.** 그래서 Windows 방화벽의 "액세스 허용" 창도 뜨지 않아요. 어떤 정보도 모으거나 보내지 않아요.
- 캡처 그림 · 녹화 영상 · 최근 캡처 목록 · 설정은 모두 **내 컴퓨터 안에만** 저장돼요.
- Microsoft Defender 로 검사했을 때 위협이 발견되지 않았어요(1.3.0, 2026-10-26).
- 처음 실행할 때 파란 **"Windows의 PC 보호"** 창은 인증서를 사지 않은 프로그램이면 늘 뜨는 안내예요 → **[추가 정보] → [실행]**.
- Windows 11 의 **스마트 앱 컨트롤**이 **켜짐**인 PC에서는 인증서가 없는 프로그램이 실행되지 않을 수 있어요.
  ([설정] → [개인 정보 및 보안] → [Windows 보안] → [앱 및 브라우저 컨트롤] → [스마트 앱 컨트롤]에서 확인)
- 이름 끝에 N · KN 이 붙은 Windows 는 녹화에 **'미디어 기능 팩'** 이 필요해요(웅캡처가 안내해 줘요).

## 지우기

- Windows **[설정] → [앱] → [설치된 앱]** → 웅캡처 옆 **[⋯] → [제거]**
- 또는 강아지 아이콘 오른쪽 단추 → **[프로그램 정보…] → [프로그램 지우기…]**
- 저장해 둔 캡처 그림과 녹화 영상은 지워지지 않아요.

**고쳐서 다시 배포하거나 판매 · 역분석하는 것은 안 돼요.** 자세한 조건은 압축 안 `EULA.txt` 를 보세요.
