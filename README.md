## 설치하기

1. 받은 `hatelist01-windows.zip` 을 마우스 오른쪽 단추로 누르고 **[모두 압축 풀기]** 를 고릅니다.
2. 풀린 폴더 안의 **hatelist01.exe** 를 두 번 누릅니다.
3. 파란 창 **"Windows의 PC 보호"** 가 뜨면 **[추가 정보]** → **[실행]** 을 누릅니다.
   (인증서를 사지 않은 작은 무료 프로그램이라 처음 한 번 보이는 안내예요.)
4. **"hatelist01 설치"** 창에서 **[설치하기]** 를 누르면 끝!
   화면 오른쪽 아래(시계 옆)에 강아지 아이콘이 생겨요. 안 보이면 작업 표시줄의 **[^]** 를 눌러 보세요.

설치는 내 계정에만 되고(`%LOCALAPPDATA%\Programs\hatelist01`), 관리자 권한은 필요 없어요.
설치가 끝나면 받은 압축 파일과 풀린 폴더는 지워도 돼요.

## 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| 캡처 시작 | **Alt + 2** (트레이 메뉴 '단축키 설정…'에서 바꿀 수 있어요) |
| 원하는 부분만 | 끌어서 고르기 |
| 창 하나만 | 마우스를 창 위에 두고 한 번 누르기 |
| 화면 전체 | 위쪽 막대의 **[전체화면]** |
| 그만두기 | **Esc** |

- 캡처하면 **바로 복사**돼요. 카카오톡 · 메일 등에 **Ctrl + V** 로 붙여 넣으면 돼요.
- 편집기: 펜 · 형광펜 · 사각형 · 원 · 화살표 · 글자 · 모자이크
  — **Ctrl + C** 복사, **Ctrl + S** 저장, **Ctrl + Z** 되돌리기, **Esc** 닫기
- 강아지 아이콘을 오른쪽 단추로 누르면 창 캡처 · 전체화면 캡처 · 저장 폴더 열기 · 자동 실행 · 프로그램 정보 메뉴가 나와요.

## 지우기

- Windows **[설정] → [앱] → [설치된 앱]** → hatelist01 옆 **[⋯] → [제거]**
- 또는 강아지 아이콘 오른쪽 단추 → **[프로그램 정보…] → [프로그램 지우기…]**
- 저장해 둔 캡처 그림은 지워지지 않아요.
